# Security policy

## Reporting a vulnerability

Please report security problems privately through
[GitHub's private vulnerability reporting](https://github.com/elarion-game-dev/elarion-game-dev.github.io/security/advisories/new).
Don't open a public issue for them.

You'll get a reply within a few days. Please give me reasonable time to fix the problem before you disclose it.

## Scope

- The website at https://elarion-game-dev.github.io/ (pages, scripts, Content Security Policy)
- The admin page at `/admin/` and its use of the GitHub API

Out of scope: the email provider's own systems (report those to the provider), and GitHub Pages itself.
